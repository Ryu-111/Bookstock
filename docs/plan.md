# 実装計画

各マイルストーンは1つのPRにまとめ、`npm run check` とCIを通す。開発は `jh claude` / `jh codex` で行う。

| #     | 内容                                                                                                                    | 完了条件                                                                           |
| ----- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| M0    | 開発ハーネス、設計ドキュメント、雛形、Pagesのworkflow                                                                   | `npm run check` が通る。`/Bookstock/` で雛形が表示される                           |
| M1    | `src/domain`（型・検証）と `src/lookup`（openBD / NDL / Google Books のクライアントとパーサー）。NDLのCORSをspikeで確認 | 合成fixtureでパース・失敗経路（タイムアウト、404、壊れたJSON/XML）をテスト         |
| M2    | `src/storage`（IndexedDBのリポジトリ、エクスポート・インポート、移行）                                                  | 往復で記録が一致する。不正なファイルでは何も書かない（fake-indexeddbなどでテスト） |
| M3 ✅ | 登録画面とスキャナー、手入力                                                                                            | 偽カメラでISBNを読み取れる（実機は未確認）                                         |
| M4    | 本棚と記録の編集、ハッシュルーティング                                                                                  | 形式・状態の絞り込み、記録の追加・編集・削除                                       |
| M5    | 統計とSVGグラフ                                                                                                         | 集計関数のテスト。形式別に表示される                                               |
| M6    | PWA（manifest、Service Worker）、永続ストレージ、エクスポートの催促                                                     | オフラインで起動・記録できる                                                       |

- openBDの提供状況（v1は2023年に終了が発表された。ADR-0003の追記を参照）。
- キーなしのGoogle Booksが、利用者のIPで429にならずに使えるか。
