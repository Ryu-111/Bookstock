# ADR-0005: 形式（紙 / 電子 / オーディオ）は本ではなく読書記録に持たせる

- ステータス: 承認済み
- 日付: 2026-10-31
- 決定者: ryu

## コンテキスト

同じ作品を紙で読み、後でAudibleで聴き直すことがある。電子書籍・オーディオブックにはISBNがないことが多い。統計は形式別に分けたい。

## 決定

- `Book` は書誌情報だけを持つ。`Record` が `format`（`paper` / `ebook` / `audiobook`）と `platform`（Kindle、Audibleなど）を持つ。
- 1冊の `Book` に、形式の違う `Record` を複数作れる。
- 量の単位は、紙・電子ではページ、オーディオでは分にする（`ReadingLog.pages` / `minutes`、`Record.totalMinutes`）。

## 検討した選択肢

- `Book` に形式を持たせ、紙版と電子版を別の本として登録する: 単純だが、同じ作品の記録がばらばらになり、重複登録も起きやすい。

## 結果

- 「読了冊数」は、読了した `Record` の数で数える。同じ本を2形式で読了したら、形式別にはそれぞれ1冊、合計は2記録になる。ユニークな本の数も合わせて表示する。
