# ADR-0002: Vite + TypeScript + Preact、ハッシュルーティング、PWA

- ステータス: 承認済み
- 日付: 2026-10-31
- 決定者: ryu

## コンテキスト

開発ハーネスはjev-routerと同じ（TypeScript strict / ESM、ESLint、Prettier、Node標準テスト＋tsx）。スマホでの利用が中心で、バンドルを小さく保ちたい。Pagesは `/Bookstock/` のサブパスで配信され、存在しないパスは404になる。

## 決定

- ビルドはVite、UIはPreact（約4KB）を使う。`base: '/Bookstock/'`。
- ルーティングは `#/...` のハッシュ方式にする。404.htmlを使う転送はしない。
- グラフは依存を足さず、SVGで自作する。
- M6でmanifestとService WorkerによるPWAにする。

## 検討した選択肢

- React: 機能は同じだがバンドルが大きい。
- 素のDOM: 依存はゼロだが、フォームと一覧の状態管理が煩雑になる。
- Chart.jsなどのグラフライブラリ: 描画は楽だが、必要なのは数種類の棒グラフとヒートマップなので、まずは自作する。必要になったら再検討する。

## 追記（2026-10-31、見た目）

見た目は、Appleのヒューマンインターフェイスガイドライン（iOS）を参考にした独自のスタイルにする（ユーザーの希望）。Material Designは採らない。

- 下部のタブバー（本棚 / 登録 / 設定、すりガラス）と、各画面の大きなタイトル。
- 入力と設定は、角丸のグループに行が並ぶ形（inset grouped list）。形式はセグメントコントロール、評価は星。
- 色はiOSのシステムカラーに近い値で、ライト / ダークに対応する。アクセントはオレンジ。本文17px、タップ領域は44px以上。
- 部品は `src/ui/ios.tsx`、スタイルは `src/styles.css`。Appleのロゴ・SF Symbolsなどの素材は使わず、アイコンは独自の線画にする。
- CSSフレームワークやUIライブラリは追加しない。

### 追記（2026-11-13、Astryx の見た目に変更）

- 利用者の依頼で、見た目の基準を iOS 風から Meta の Astryx（Neutral テーマ、MIT）に変えた。
- Astryx のライブラリ（React と StyleX）は入れない。この製品は Preact で、依存を増やさない方針のため。`@astryxdesign/theme-neutral` と `@astryxdesign/core`（0.7.15）の CSS から値だけを写し、`src/styles.css` の CSS 変数で再現する。
- 写した値: 色（白黒のアクセント、本文の背景 #f1f1f1／#1b1b1b、面 #ffffff／#262626、線 8%／10%）、角丸（入れ物 12px、部品 10px）、影（shadow-low）、文字（本文 16px・行間 1.5、見出しは semibold）。
- 書体の Figtree は読み込まない。外部への通信を増やさないためで、Astryx の代替と同じシステムの書体を使う。
- 画面の構成（タブバー、グループの一覧、シート）と、44px 以上のタップ領域は変えない。グラフの形式の3色は、検証済みの値をそのまま使う。
